# 0034 – Cash Market Pro: layout și chart CEA

## Context

Pe pagina CEA Cash (`/cash-market`, `CashMarketProPage`), utilizatorul cere modificări de layout și implementarea unui chart financiar. Conform atașamentelor și specificațiilor:

- Containerul principal (`div.page-container py-6`) să fie flex până la baza paginii
- Div-ul pentru introducere ordin să se mute sub tickerul "Recent Trades (last 20)"
- Componenta `RecentTradesActivity` (ACTIVITY last 20) să se mute sub order book
- În zona roșie (sub order book / lângă ACTIVITY) să se implementeze un chart cu același stil de container ca `RecentTradesActivity`, care se actualizează cu prețul fiecărei noi tranzacții și folosește toate datele din baza de date; nivel de complexitate ca un chart financiar mediu–complex

## Fișiere relevante

| Fișier | Acțiune |
|--------|---------|
| `frontend/src/pages/CashMarketProPage.tsx` | Layout: flex page container, mutare ordine componente, integrare chart |
| `frontend/src/hooks/useCashMarket.ts` | Opțional: chart trades separate (limit 100) sau reutilizare recentTrades cu limit configurat |
| `frontend/src/components/cash-market/CEAPriceChart.tsx` | Nou: componenta chart (stil container RecentTradesActivity) |
| `frontend/src/services/api.ts` | getRecentTrades suportă deja `limit` (1–100); nu necesită modificări |
| `frontend/package.json` | Adăugare dependență chart (ex. `lightweight-charts`) |

## Stil container chart

Chart-ul va folosi exact aceleași clase ca `RecentTradesActivity`:

- `bg-navy-900 rounded border border-navy-700 overflow-hidden`
- Header similar: iconă (ex. TrendingUp), titlu, `overflow-y-auto` / `overflow-hidden` pentru conținut

## Specificații layout

### 1. Page container flex

- `div.page-container py-6` → `flex flex-col flex-1 min-h-0` (sau echivalent) astfel încât conținutul să se extindă până la baza paginii
- Părintele `div.min-h-screen bg-navy-900` trebuie să fie `flex flex-col` pentru ca flex-1 să funcționeze

### 2. Ordinea componentelor (top → bottom)

1. **Ticker** – Recent Trades (last 20), lg:col-span-8 (sau full width)
2. **Order input** – InlineOrderForm, imediat sub ticker
3. **Order book** – ProfessionalOrderBook
4. **Grid cu 2 coloane**:
   - Coloana stânga (sau full width pe mobile): **ACTIVITY** (RecentTradesActivity) – mutat sub order book
   - Coloana dreapta (sau sub ACTIVITY pe mobile): **Chart** – nou, în zona roșie

Layout concret:

```
[Ticker – full width]
[InlineOrderForm – sub ticker]
[Order Book – full width]
[Grid: ACTIVITY (lg:col-span-4) | Chart (lg:col-span-8)]
```

Sau varianta: ACTIVITY și Chart unul sub altul, ambele full width, ordinea ACTIVITY apoi Chart.

Conform descrierii, ACTIVITY se mută sub order book; chart-ul ocupă "zona roșie" (spațiul gol de la baza paginii). Deci:

```
[Ticker]
[InlineOrderForm]
[Order Book]
[ACTIVITY | Chart]  — grid 2 coloane, ACTIVITY stânga, Chart dreapta (sau invers)
```

### 3. Chart – date și actualizare

- **Sursă date**: `GET /api/v1/cash-market/trades/CEA?limit=100` (API permite 1–100)
- **Actualizare real-time**: listener `nihao:tradeExecuted` – la fiecare trade nou, chart-ul primește punctul nou (preț, timestamp) și se re-renderează / actualizează
- **Tip chart**: serie temporală preț vs timp (line sau area); nivel mediu–complex = grid, axe, tooltip la hover, crosshair, eventual volume bars
- **Bibliotecă**: `lightweight-charts` (TradingView) – adaptată pentru charturi financiare, suportă real-time updates; sau SVG custom (ca `PriceHistoryChart` din SettingsPage) dacă se preferă zero dependențe noi

## Algoritm chart

1. **Fetch inițial**: la mount, `cashMarketApi.getRecentTrades('CEA', 100)` – ordonare desc by executed_at (API returnează deja desc)
2. **Transformare**: `trades` → `[{ time: unix_sec, value: price }]` pentru lightweight-charts; sau array de `{ executedAt, price }` pentru SVG
3. **Render**: line/area series; Y = preț, X = timp
4. **WebSocket**: la `nihao:tradeExecuted`, prepend punct nou în serie; chart se actualizează
5. **Stil**: culori emerald (uptrend) / red (downtrend) conform design system; fundal navy, grid discret

## Reguli

- Conform `app_truth.md` și `frontend/docs/DESIGN_SYSTEM.md`: culori navy, emerald, amber, red; fără slate/gray
- `CashMarketProPage` nu e în lista frozen din app_truth.md §10
- Nu se folosesc date mock – doar API și WebSocket real
- `useCashMarket` poate fi extins cu `chartTrades` (limit 100) sau chart-ul poate face fetch propriu; preferabil fetch separat pentru chart ca să nu afecteze ticker/ACTIVITY (care rămân la 20)
