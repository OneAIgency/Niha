# Feature 0041: Scraping EUA de la Trading Economics

## Summary

Adăugarea unui sursă de scraping pentru prețul EU Carbon Permits (EUA) de pe Trading Economics (`https://tradingeconomics.com/commodity/carbon`). Infrastructura de scraping există deja; planul definește configurația corectă bazată pe path-ul DOM furnizat de utilizator.

**Detalii verbatim din cerere**:

- **URL**: `https://tradingeconomics.com/commodity/carbon`
- **DOM Path**: `form#aspnetForm > div.container > div.row te-content > div.col-xl-8 col-lg-8 > div.table-re.pon.ive market.2 market-border > div.table-minimize > div.card > table.table table-hover .ortable-theme-minimal table-heatmap table-.triped > tbody > tr[3] > td#p`
- **Element**: `<td id="p">71.25</td>` — celula cu prețul EU Carbon Permits (ex: 71.25)
- **Poziție**: top=752px, left=254px, width=89px, height=41px

## Context (app_truth.md, ADMIN_SCRAPING.md)

- Scrapingul generic (non-carboncredits.com) extrage prețul din HTML folosind `config`: `xpath_selector`, `css_selector` sau `regex_pattern`.
- XPath are prioritate, apoi CSS, apoi regex.
- Settings UI (Add/Edit Source) expune doar câmpul **XPath selector**; backend-ul acceptă și `css_selector` în config.
- `docs/ADMIN_SCRAPING.md` conține deja un exemplu pentru Trading Economics cu un XPath alternativ: `tr[4]/td[2]`. Planul actual folosește selectorul derivat din path-ul furnizat: `tr[3]` + `td#p`.

## Selectori recomandați

Derivate din DOM path:

1. **xpath_selector** (recomandat — cel mai robust):
   ```
   //form[@id='aspnetForm']//table[contains(@class,'table')]//tbody/tr[3]/td[@id='p']
   ```
   Sau variantă mai scurtă (dacă `td#p` este unic în pagină):
   ```
   //td[@id='p']
   ```
   ⚠️ `id="p"` poate fi neunic; preferați varianta cu form + table + tr[3] pentru stabilitate.

2. **css_selector** (fallback, dacă XPath eșuează):
   ```
   form#aspnetForm table.table tbody tr:nth-of-type(3) td#p
   ```

## Fișiere și acțiuni

### Configurare (fără cod nou)

Sursa se adaugă prin **Settings → Price Scraping Sources → Add Source** sau prin API:

| Câmp | Valoare |
|------|---------|
| name | Trading Economics EUA |
| url | `https://tradingeconomics.com/commodity/carbon` |
| certificate_type | EUA |
| scrape_library | HTTPX |
| scrape_interval_minutes | 5 (sau alt interval) |
| is_primary | false (sau true dacă vreți să devină principală) |
| config | `{"xpath_selector": "//form[@id='aspnetForm']//table[contains(@class,'table')]//tbody/tr[3]/td[@id='p']"}` |

Exemplu API (documentat în ADMIN_SCRAPING.md):

```http
POST /api/v1/admin/scraping-sources
```

```json
{
  "name": "Trading Economics EUA",
  "url": "https://tradingeconomics.com/commodity/carbon",
  "certificate_type": "EUA",
  "scrape_library": "httpx",
  "scrape_interval_minutes": 5,
  "is_primary": false,
  "config": {
    "xpath_selector": "//form[@id='aspnetForm']//table[contains(@class,'table')]//tbody/tr[3]/td[@id='p']"
  }
}
```

### Opțional: fallback în UI

Settings UI (`frontend/src/pages/SettingsPage.tsx`) expune doar `xpath_selector`. Dacă XPath-ul nu se potrivește după schimbări pe site-ul Trading Economics, admin-ul poate încerca manual `css_selector` prin direct edit la `config` în DB sau prin extinderea UI (câmp suplimentar „CSS selector” în Add/Edit modal). Nu este parte obligatorie a acestui plan.

## Algoritm (extragere preț — existent în price_scraper.py)

1. `scrape_source()` → httpx GET la URL
2. `_extract_price()` citește `config.xpath_selector`
3. `_extract_via_xpath(content, xpath)` folosește lxml pentru XPath
4. `_parse_price(text)` curăță simboluri (€$¥£,\s) și convertește la float

## Consistență

- Respectă fluxul generic din `ADMIN_SCRAPING.md`: URL non-carboncredits.com → fetch HTML → extract via config.
- Prețul este în EUR; `currency` pentru PriceHistory va fi „EUR” pentru EUA.
- Scheduler-ul va rula refresh la fiecare `scrape_interval_minutes`; Test și Refresh sunt disponibile din Settings UI.

## Note

- **Rând tabel**: Utilizatorul a indicat `tr[3]` (al treilea rând din tbody). Dacă structura paginii se schimbă (ex: rând nou inserat), XPath-ul poate necesita ajustare. Alternativa `//td[@id='p']` e mai fragilă dacă există mai multe elemente cu `id="p"`.
- **Rate limit**: Trading Economics poate returna 429; backend-ul aplică deja mapare de eroare (vezi ADMIN_SCRAPING.md, Error mapping). Nu există backoff specific Trading Economics; doar carboncredits.com are Redis backoff.
