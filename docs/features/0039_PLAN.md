# Feature 0039: Resizable panels cu mouse în interfața grafică

## Summary

Permite utilizatorului să redimensioneze div-urile/panourile din interfața grafică folosind mouse-ul. Utilizatorul trage cu mouse-ul pe un mâner (handle) între panouri pentru a ajusta dimensiunile relative. Dimensiunile vor persista în localStorage pe sesiune, per pagină.

## Technical Approach

### Library

Folosirea **react-resizable-panels** (npm: `react-resizable-panels`), librărie populară și bine menținută care:
- Suportă `Panel` + `PanelResizeHandle` (horizontal și vertical)
- Compatibilă cu flex layout
- Fără dependențe heavy; API simplu
- Accesibilitate: drag cu mouse, cursor vizual (col-resize / row-resize)

### Algoritm de resize

1. Mouse down pe handle → `pointer-events: capture` pe handle, listener global pentru mousemove/mouseup
2. Mousemove → calculează delta (px) față de poziția anterioară
3. Actualizează dimensiunile panourilor adiacente (în % sau fr)
4. Mouseup → release capture, oprește listener-ele
5. La resize final → salvează proporțiile în localStorage (cheie per pagină, ex: `niha_layout_cash_market_pro`)

### Persistență

- Cheie localStorage: `niha_layout_{pageKey}` (ex: `niha_layout_cash_market_pro`, `niha_layout_swap`)
- Valori: JSON cu procente sau valori fr pentru fiecare panel (ex: `{ "row1": [0.4, 0.35, 0.25], "row2": [0.33, 0.33, 0.34] }`)
- Fallback: dimensiuni implicite (egale sau cele curente col-span-echivalente)
- Nu persista pe mobile (viewport < 768px) — layout fix

## Design System Compliance

- **Handle styling**: border `navy-700`, hover `navy-600`, width 4–6px (orizontal) / height 4–6px (vertical); cursor `col-resize` (vertical handle) sau `row-resize` (orizontal)
- **Min size**: fiecare panel trebuie să aibă `minSize` (ex: 15–20%) ca să nu dispară complet
- **Culori**: fără slate/gray; folosire exclusivă navy, emerald, amber per `tailwind.config.js`
- **Accessibility**: handle cu `role="separator"` și `aria-orientation`; suport键盘 (optional: taste să mute focus între panouri)

## Frozen Files

CashMarketProPage **nu** este în lista frozen (§10 app_truth). Onboarding, LoginPage, etc. rămân nemodificate. Feature-ul nu afectează fișiere frozen.

## Implementation Notes

1. **Skeleton loading**: păstrat; structura ResizablePanelGroup se montează doar când `!loading && orderBook`
2. **Mobile**: sub `md` (768px) nu folosi ResizablePanelGroup; păstrează layout grid fix responsive ca acum
3. **CEAPriceChart**: deja folosește ResizeObserver; se va redimensiona automat când containerul (Panel) își schimbă dimensiunea
4. **Default sizes**: Row 1 → [5/12, 4/12, 3/12] ≈ [41.67, 33.33, 25]; Row 2 → [1/3, 1/3, 1/3]
